# Interactive Voting API

Interactive Voting API, это учебный серверный проект для организации электронного голосования. Система позволяет вести список избирателей, кандидатов, заявок кандидатов, выборов, голосов и журнал действий администратора.

## Назначение проекта

Проект разработан в рамках практической части дипломной работы. Его можно использовать как основу для демонстрации работы API электронного голосования:

- регистрация избирателей;
- проверка избирателей;
- добавление кандидатов;
- подача и рассмотрение заявок кандидатов;
- создание выборов;
- прием голосов;
- закрытие выборов;
- получение результатов;
- сохранение действий в журнал аудита.

## Технологии

- C#;
- ASP.NET Core Web API;
- .NET 6;
- Entity Framework Core;
- SQLite;
- Swagger / OpenAPI.

## Требования для запуска

Перед запуском нужно установить:

- .NET 6 SDK или новее;
- Git, если проект загружается из репозитория;
- любой браузер для открытия Swagger.

Проверка установки .NET:

```bash
dotnet --version
```

## Запуск через bat-файл на Windows

1. Распакуй архив или скачай проект из GitHub.
2. Открой папку проекта.
3. Запусти файл `START_PROJECT.bat` двойным кликом.
4. Открой Swagger в браузере:

```text
http://localhost:5055/swagger
```

## Запуск через терминал

```bash
dotnet restore
dotnet build
dotnet run --urls http://localhost:5055
```

После запуска открой:

```text
http://localhost:5055/swagger
```

## База данных

Проект использует SQLite. Файл базы данных создается автоматически при первом запуске приложения. Строка подключения находится в файле `appsettings.json`.

Схема базы данных дополнительно вынесена в файл:

```text
database/schema.sql
```

## Проверка работы проекта

Проверку удобно выполнять через Swagger.

### Тестовый сценарий 1. Создание избирателя

1. Открой `POST /api/voters`.
2. Передай данные избирателя.
3. Проверь, что запись появилась через `GET /api/voters`.

Пример тела запроса:

```json
{
  "fullName": "Иванов Иван Иванович",
  "dateOfBirth": "2000-01-01T00:00:00Z",
  "passportNumber": "1234567890",
  "email": "ivanov@example.com",
  "phoneNumber": "+79990000000"
}
```

### Тестовый сценарий 2. Создание кандидата

1. Открой `POST /api/candidates`.
2. Создай кандидата.
3. Проверь список кандидатов через `GET /api/candidates`.

### Тестовый сценарий 3. Подача заявки кандидата

1. Открой `POST /api/applications`.
2. Передай `candidateId`.
3. Одобри заявку через `POST /api/applications/{id}/approve`.
4. Проверь, что кандидат получил статус `isApproved = true`.

### Тестовый сценарий 4. Создание выборов и голосование

1. Создай выборы через `POST /api/elections`.
2. Подтверди избирателя через `POST /api/voters/{id}/verify`.
3. Отдай голос через `POST /api/voting/cast`.
4. Получи результаты через `GET /api/elections/{id}/results`.
5. Проверь журнал через `GET /api/audit`.
