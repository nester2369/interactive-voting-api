# Чек-лист перед публикацией репозитория

- [ ] В репозитории есть `README.md` с описанием проекта.
- [ ] В `README.md` указаны технологии, запуск, сборка и проверка.
- [ ] В `README.md` указан список ИИ-инструментов и ссылки на официальные ресурсы.
- [ ] В папке `docs/` есть ERD-диаграмма.
- [ ] В папке `docs/` есть UML-диаграмма модулей и бизнес-логики.
- [ ] В папке `database/` есть SQL-схема базы данных.
- [ ] В проекте есть исходные `.cs` файлы.
- [ ] В исходных файлах есть осмысленные комментарии.
- [ ] В проекте есть `.gitignore`.
- [ ] В репозиторий не загружены `bin/`, `obj/`, `.exe`, `.dll`, локальная база `*.db`.
- [ ] Репозиторий открыт для проверки.
